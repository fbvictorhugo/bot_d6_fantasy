 # 🤖 D6 Express

**Discord bot for the [D6 Fantasy Express](#-about-d6-fantasy-express) tabletop RPG system.**

D6 Express is a lightweight Discord bot designed to make **D6 Fantasy Express** games faster and easier to play directly from Discord.

The first version focuses on the core mechanic of the system: **2d6 dice rolls with attribute modifiers**.

---

## 🎲 Dice Roller

The D6 Fantasy Express core mechanic uses **2 six-sided dice (2d6)** plus an attribute modifier.

### Basic Roll

```text
2d6 + Attribute
```

The result determines the outcome:

🟢 **10+** — Full Success
🟡 **7–9** — Success with a Cost
🔴 **6 or less** — Failure / GM Threat

### Example

```text
Player: /roll 2
Bot: 🎲 4 + 3 + 2 = 9
     🟡 Success with a Cost
```

The modifier can represent one of the character's attributes:

* 💪 **Strength (FOR)**
* 🏃 **Agility (AGI)**
* 🧠 **Mind (MEN)**

## 🧙‍♂️ About D6 Fantasy Express

**D6 Fantasy Express** is a fast, intuitive, and modern tabletop RPG designed to introduce new players to role-playing games without the barriers of complex rules or endless character sheets.

The system uses only **two six-sided dice (2d6)** and combines narrative mechanics inspired by **Powered by the Apocalypse (PbtA)** with traditional RPG elements such as:

* Fixed Hit Points
* Character attributes
* Weapons and armor
* Damage rolls
* Simple equipment
* Classes and races
* Spells and special abilities

The core resolution mechanic uses three result tiers:

| Roll    | Result              |
| ------- | ------------------- |
| **10+** | Full Success        |
| **7–9** | Success with a Cost |
| **6−**  | Failure / GM Threat |

The goal is to keep the game **fast, accessible, and focused on the adventure**, rather than on complicated rules.
